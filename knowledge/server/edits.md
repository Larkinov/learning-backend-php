# Редакторы

## NANO

Выделение текста:

```
1. Cначала отмечается начало выделение - Alt+A или Ctrl+^
2. Далее следует навигация до момента выполнения действия над текстом в буфере, выделение сохраняется
```

Горячие клавиши:
```
копировать - Alt+6
вырезать - Ctrl+K (или F9)
вставить - Ctrl+U или F10
удалить - Alt+T (удаляет до указателя мыши);
```

Переход на определенный номер строки в файле:
```
Ctrl+_ затем ввод строки
```
Открыть новый файл в nano, не выходя из текущего:
```
Ctrl+R (это команда для вставки другого файла)
```
